# Big Two – spelregelafbeelding openen en zoomen

## Nieuwe werking

- Tik op de korte spelregelafbeelding om die schermvullend te openen.
- Gebruik `+` en `−` om te zoomen.
- Gebruik `100%` om de oorspronkelijke weergave te herstellen.
- Op telefoon werkt knijpen om te zoomen.
- Bij ingezoomde weergave kan de afbeelding worden versleept.
- Dubbelklik of dubbeltik wisselt tussen 100% en 200%.
